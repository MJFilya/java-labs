# Лабораторная работа 3 — «Универсальное хранилище»

Консольное приложение «Универсальное хранилище» для хранения строк и целых чисел в обычном массиве: добавление, получение, замена и удаление элементов, проверка переполнения и неверного индекса

## Запуск

Нужна Java 25 или новее

```
cd storage
javac -encoding UTF-8 *.java
java Main
```
