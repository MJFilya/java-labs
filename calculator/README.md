# Лабораторная работа 4 — «Универсальный калькулятор»

Консольное приложение «Универсальный калькулятор» для работы с целыми и дробными числами: сложение, вычитание, умножение, деление, среднее арифметическое и квадрат числа

## Запуск

Нужна Java 25 или новее

```
cd calculator
javac -encoding UTF-8 *.java
java Main
```
