# Лабораторная работа 2 — «Автопарк»

Консольное приложение «Автопарк» для работы с несколькими видами транспорта: список транспорта, движение каждого вида и особые действия легкового автомобиля, мотоцикла и грузовика

## Запуск

Нужна Java 25 или новее

```
cd autopark
javac -encoding UTF-8 *.java
java Main
```
